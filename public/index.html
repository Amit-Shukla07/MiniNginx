Core Architectural Highlights

Engineered for low latency, zero leaks, and predictable resource bounds.

🔄

I/O Multiplexing

Native kernel event demultiplexing with kqueue/kevent on Darwin and epoll on Linux, eliminating thread-per-connection overhead.

⚡

Zero-Copy File Transfer

Direct kernel-space file streaming via platform-specialized sendfile() syscalls, bypassing user-space buffer copies.

🧩

Incremental FSM Parser

Deterministic zero-copy finite state machine supporting fragmented packets, pipelined requests, and chunked transfer encoding.

⏱️

Heap-Based Timers

Precise O(log N) min-heap timer manager preventing idle socket exhaustion (Slowloris attacks) and enforcing keep-alive deadlines.

🛡️

Defensive Security

Strict path canonicalization against directory traversal (../../ attacks) and bounded request header/body buffers.

👥

Multi-Worker Scaling

Independent event-loop per worker thread with lock-free connection assignment and atomic runtime metrics aggregation.
